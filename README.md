## WHY THIS EXISTS

CORESYNC AUTOMATES SYSTEM DESIGN REVIEWS WITH COMPLETENESS CONSISTENCY AND STRUCTURE CHECKS PRODUCING A SINGLE SCORE AND CLEAR VERDICT

## INSTALL

```bash
git clone https://github.com/cyc3o/CoreSync
cd CoreSync
python main.py
```

ZERO DEPENDENCIES RUNS ON PURE PYTHON 3.12+ NOTHING ELSE TO SET UP
